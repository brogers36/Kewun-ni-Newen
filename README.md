# Kewün ñi Newen

*Kewün ñi Newen* ("the strength of the language") is a retro action RPG for learning Mapudungun. It is drawn in the style of *A Link to the Past*, *EarthBound* and *Final Fantasy*.

The player is a young wariache, Llanka or Millaray. They travel the Mapuche lands to wake the ngen, who have been silenced by forgetting. Mapudungun grammar is the battle system: you build commands from verb roots and person endings, and they act on wekufü taken from Mapuche folklore. Each region's boss drops a trokiñ (piece) of an ancient trariwe. The five pieces together let you pass through the fog of **Ti Fütra Ngoyman**, the great forgetting, to the final boss.

## Play

Open `www/index.html` in any modern browser. It is one self-contained file and needs no server or internet connection. Progress is saved in the browser's localStorage.

Controls: arrow keys or WASD to move; Z, Space or Enter for A (talk, confirm); X, Escape or Backspace for B (back); M for the menu; N to mute. On a phone, use the on-screen pad.

## Building

Python 3 is the only requirement.

```
python3 tools/maps.py   # only if you changed the maps; regenerates src/maprows.js
python3 build.py        # writes www/index.html
```

### Master copy (for testing)

```
python3 build.py --master   # writes master/index.html (not committed)
```

The master copy has a «Maestro · Elegir región» button on the title screen that starts the game at any checkpoint (the start of a region, its lof, its dungeon entrance, its boss, or the region finished), with the earlier regions already completed and the hero at a matching level. In the game, G (or the MAE button on the phone pad) opens the master menu: jump to any map, heal, add ngülliw, turn ordinary battles off, or win the current battle. It saves separately from the player version, so testing never touches a real save. When a new region is added, add its checkpoints to `MCHK` and `MSET` in `src/master.js`.

### Chrono Trigger-style preview

```
python3 build.py --master       # writes ct/index.html (not committed)
```

An experimental look switched on by the `CT` flag: painterly dithered grass, sand and paths; leafy canopy trees; soft shadows; warm light around fires and a vignette; battles fought on the field itself with blue gradient windows. It includes the master tools. The player build is unchanged.

## Toward a phone app

The game is a single HTML page with touch controls, built into `www/`. That folder is the layout [Capacitor](https://capacitorjs.com/) expects, so wrapping it as an Android or iOS app needs only a few commands and no changes to the game code:

```
npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android @capacitor/ios
npx cap init "Kewün ñi Newen" cl.kewun.newen --web-dir www
npx cap add android      # needs Android Studio
npx cap add ios          # needs a Mac with Xcode
npx cap sync             # run again after each build.py
```

A lighter option is to make it an installable web app (PWA) by adding a `manifest.json` and a service worker to `www/`. Players can then add it to their home screen from the browser.
