# Kewün Newen

*Kewün Newen* ("the strength of the language") is a retro action RPG for learning Mapudungun. It is drawn in the style of *A Link to the Past*, *EarthBound* and *Final Fantasy*.

The player is a young wariache: Millaray, Ayelen, Llanka or Kallfürüngi, chosen on the title screen. They travel the Mapuche lands to wake the ngen, who have been silenced by forgetting. Mapudungun grammar is the battle system: you build commands from verb roots and person endings, and they act on wekufü taken from Mapuche folklore. Each region's boss drops a trokiñ (piece) of an ancient trariwe. The five pieces together let you pass through the fog of **Ti Fütra Ngoyman**, the great forgetting, to the final boss.

## Play

Open `www/index.html` in any modern browser. It is one self-contained file and needs no server or internet connection. Progress is saved in the browser's localStorage.

Controls: arrow keys or WASD to move; Z, Space or Enter for A (talk, confirm); X, Escape or Backspace for B (back); M for the menu; N to mute. On a phone there are no on-screen buttons: tap to talk, confirm or advance speech; hold a finger down and drag to walk (keep holding to keep walking, lift to stop); swipe to scroll a menu; two-finger tap to go back; long-press for the pause menu. The phone app runs in landscape.

  render.js     map, HUD and battle rendering

## Building

Python 3 is the only requirement.

```
python3 tools/maps.py   # only if you changed the maps; regenerates src/maprows.js
python3 build.py        # writes www/index.html
```

### Master copy (for testing)

```
python3 build.py --master   # writes master/index.html (not committed)
```

The master copy has a «Maestro · Elegir región» button on the title screen that starts the game at any checkpoint (the start of a region, its lof, its dungeon entrance, its boss, or the region finished), with the earlier regions already completed and the hero at a matching level. In the game, G (or the MAE button on the phone pad) opens the master menu: jump to any map, heal, add ngülliw, turn ordinary battles off, or win the current battle. It saves separately from the player version, so testing never touches a real save. When a new region is added, add its checkpoints to `MCHK` and `MSET` in `src/master.js`.

### Chrono Trigger-style preview

```
python3 build.py --master       # writes ct/index.html (not committed)
```

An experimental look switched on by the `CT` flag: painterly dithered grass, sand and paths; leafy canopy trees; soft shadows; warm light around fires and a vignette; battles fought on the field itself with blue gradient windows. It includes the master tools. The player build is unchanged.

## Phone app

The game is installable on phones two ways, both fed by this repo:

**Installable web app (PWA), iPhone and Android.** `www/` now carries `manifest.webmanifest`, a service worker (`sw.js`) and icons, so the GitHub Pages site is installable: open <https://brogers36.github.io/Kewun-ni-Newen/> on the phone, then *Add to Home Screen* (Safari: Share menu; Android Chrome offers an install prompt). It launches fullscreen with its own kultrung icon and keeps working offline after the first load; when online again it picks up the latest build automatically: each build carries an id, the game compares it against `www/version.txt` on launch and on returning to the app, reloads itself at the title screen when a newer build exists, and shows a tap-to-update notice if a game is in progress. Saves live in the installed app's own localStorage.

**Downloadable Android APK.** `.github/workflows/android.yml` wraps `www/` with [Capacitor](https://capacitorjs.com/) on every push and publishes a signed APK to the rolling release, always at the same link:

> <https://github.com/brogers36/Kewun-ni-Newen/releases/download/android/KewunNiNewen.apk>

Android users download it from the [Releases page](https://github.com/brogers36/Kewun-ni-Newen/releases/tag/android) and allow installing from that source once. The APK is a thin shell that loads the live GitHub Pages build, so installed copies pick up every pushed update automatically on their next online launch (first launch needs internet; after that the service worker keeps it playable offline). Re-downloading the APK is only needed if the shell itself changes. The APK is signed with a private release key held in two repository secrets (`ANDROID_KEYSTORE_B64`, `ANDROID_KEYSTORE_PASSWORD`); if either is missing the workflow stops before publishing, so the APK at the link stays in place. The earlier public key (`android-signing/`) was retired on 2026-11-24: copies installed before then must be uninstalled once before installing the new APK. Keep an offline backup of the keystore; without it no future build can update installed copies.

The build master strips the PWA tags (`build.py --master`), so only the player copy registers the service worker.
